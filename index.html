FAQ

Questions, answered.

Do my customers need to install anything?

No. Everything happens inside WhatsApp, the app your customers already use. There is nothing else for them to download, log into or learn.

Do I need to write code?

No. Rivet is designed for no-code setup, while APIs and webhooks remain available when technical teams need deeper integrations.

Which WhatsApp API does Rivet use?

Rivet connects through Meta’s WhatsApp Cloud API.

Can I connect my existing store?

Yes. Rivet supports commerce integrations including Shopify and WooCommerce, with custom webhooks available for other systems.

How are payments handled?

Payment integrations can hand customers into checkout while Rivet keeps the conversation and order status in sync.

Is my data isolated from other businesses?

Yes. Rivet uses workspace-level isolation and role-based access controls to keep tenant data separated.
